# 文档归档

本目录用于保存旧版文档、专题文档、审查记录和计划文档。

这些文件不会删除，但不再作为当前项目的主文档入口。当前应优先查阅：

- `README.md`
- `docs/README.md`
- `docs/overview.md`
- `docs/development.md`
- `docs/deployment.md`
- `docs/database.md`
- `docs/cms.md`

## 分类

- `archive/deploy/`：旧版部署说明、专项检查表、可选部署方案
- `archive/cms/`：CMS 重构记录、待办和专题说明
- `archive/containers/`：容器说明
- `archive/infra/`：旧版基础设施说明
- `archive/legal/`：专题合规文档
- `archive/plans/`：历史计划文档
- `archive/reviews/`：历史审查记录
